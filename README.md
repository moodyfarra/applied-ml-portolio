# Applied Machine Learning Portfolio – Ahmed Farra

This repository highlights selected machine learning projects focused on applying data-driven methods to real-world problems.

## NASA & Smithsonian Coastal Carbon Project
Developed machine learning models using satellite and environmental datasets to estimate coastal biomass.  
Worked with geospatial data, feature engineering, and predictive modeling.

## AgriGuard – AI Crop Stress Detection
Built a machine learning pipeline integrating Sentinel-1, Sentinel-2, MODIS, and USDA datasets.  
Designed models to detect crop stress and predict yield risk using satellite imagery and environmental data.

## Stock Market Sentiment Analysis (Deep Learning)
Developed deep learning models using TensorFlow and Keras to analyze financial news sentiment.  
Built NLP pipelines to extract features and predict market trends.

## Customer Churn Prediction
Built classification models in Python to identify high-risk banking customers.  
Used behavioral and transactional data to support retention strategies.
